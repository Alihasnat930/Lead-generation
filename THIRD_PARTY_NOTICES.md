# Open-source and open-data sources

- **DDGS** — [deedy5/ddgs](https://github.com/deedy5/ddgs), MIT license. Used as an optional public web search adapter; no subscription or API key.
- **Overpass API** — [drolbr/Overpass-API](https://github.com/drolbr/Overpass-API). The optional public endpoint queries OpenStreetMap business listings; the server implementation is not bundled.
- **OpenStreetMap** — [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright), Open Database License (ODbL). OSM-derived records include the original object URL, attribution and license. Preserve attribution and consider the database share-alike conditions when distributing a derived database. See the [public endpoint guidelines](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html).
- **GeoNames** — [GeoNames city data](https://download.geonames.org/export/dump/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). `assets/city_coordinates.json` contains a selected/renamed subset of coordinates and IDs generated by `scripts/build_city_pack.py`. It is used for discovery centres, not as evidence of a company's address.
- **SearXNG** — [searxng/searxng](https://github.com/searxng/searxng), AGPL-3.0. Evaluated as a self-hosted search alternative; not bundled or required.

Business-site content remains attributable to the respective websites. Source URLs accompany every observed contact. No claims of data accuracy, deliverability or completeness are implied by these licenses.
